# 좁은 화면·큰 글자 레이아웃 점검 — 2026-09-29

## 확인된 문제와 변경

사용자가 제공한 Samsung Internet 랭킹 화면의 이름/탭 글자 분리가 일반 Chromium 360px에서도 재현됐다. 삼성 전용 결함으로 단정하지 않고 실제 레이아웃 결함을 수정했다.

- 랭킹: 600px 이하에서 순위·이름·날짜와 기록을 별도 행으로 배치. 티어와 이름을 별도 요소로 만들어 이름 내부의 불필요한 줄바꿈을 막는다. 이달 PR·출석 순위도 적용한다. 하위 탭은 가로로 잘리지 않도록 줄바꿈한다.
- 내 PR·그래프·공식 측정 등록: 카드의 기록/날짜/버튼과 검색 컨트롤이 자연스럽게 줄바꿈한다. 좁은 등록창의 운동 유형 선택은 한 열, 제목은 단어 단위 줄바꿈.
- 공통 티어/학년 배지: 고정16px 높이 대신 최소 높이와 비례 줄높이를 사용해 큰 글자도 배지 안에 들어가도록 한다.
- 내 정보: grid 자식의 최소 너비 때문에320px·150%에서334px로 밀리던 카드 수정. 모바일 카드 여백 축소, 수강정보 값 줄바꿈, 출석 내역2열.
- 게시판: 큰 글자에서 검색 버튼이 화면 밖으로 나가던 현상 수정. 작성자/댓글 메타정보 줄바꿈 허용.
- 내 수업·보강: 주간 상태 칩 너비 제한/단어 줄바꿈. 큰 글자에서 보강 시간/자리 표기가 겹치면 시간표 자체만 가로 스크롤하며 교시·시간 열은 고정한다. 전체 페이지는 가로로 밀리지 않는다.
- 훈련일지: 헤더·작성일·달력 범례의 줄바꿈, 날짜/검색 입력의 유연한 높이. 메인/훈련일지 하단 메뉴는 고정 높이 대신 최소 높이. 훈련일지 CSS 캐시 버전 갱신.

## 검증 범위와 결과

- 실서비스 컴포넌트를 사용하되 랭킹/게시판 서비스는 메모리 예시로 대체. 수강생/훈련일지는 기존 격리 로컬 검토 진입점을 사용. 운영 데이터 저장·글 게시·알림 전송 없음.
- 14개 화면/흐름: 종목 랭킹, 이달 PR, 출석 순위, 내 PR, 경험치 그래프, PR 등록 모달, 게시판 목록/검색, 내 수업, 보강 시간표, 내 정보, 홀딩, 코치 첫 화면, 훈련일지 달력, 기록 작성.
- 320px/412px 각각 글자150%를 모의해28조건 확인. 전부 페이지 가로 넘침 및 입력 컨트롤 화면 이탈 없음. 모바일 랭킹 이름은 테스트한4~8자 이름 모두 한 줄로 표시. 보강은 이후 추가 수정으로 시간표 내부 스크롤과 마지막 금요일 열 접근을 별도 재확인했다.
- 360px 재현 전후,390px 기본 크기 및1280px 데스크톱 랭킹 시각 점검. 보강320px·150%: 페이지320px 유지, 시간표288px 안에서392px 내용을104px 이동하여 마지막 열 접근 가능.
- 전체71파일648테스트, 변경 JSX ESLint, 프로덕션 빌드 통과. 보강 후속 변경 후 관련25테스트·빌드 재실행 통과.
- 원본 서비스 구현/데이터·계산 로직은 유지. CSS/표현용 마크업 변경.

## 재현 자료와 한계

로컬 `outputs/mobile-layout-review/`의 `build.mjs`는 실제 Ranking/PRSubmitModal/PostList를 메모리 서비스로 번들한다. `audit.mjs`, `results.json`,28개 캡처가 같은 폴더에 있다. 로컬 검토 산출물은 Git/배포에 포함하지 않는다.

글자150%는 각 요소의 계산된 font-size를1.5배로 조정한 스트레스 검증이며 Android 시스템 글자 크기·Samsung Internet 글자 확대 알고리즘과 동일하지 않다. 실제 삼성 인터넷/갤럭시 기기에서 직접 검증하지 않았다. 경험치 그래프는 빈 데이터 상태와 제어 UI를 확인했고 모든 실데이터 차트·모든 코치 관리 모달까지 검증한 것은 아니다. 추가 실기기 제보가 있으면 해당 조건에서 이어서 확인한다.
