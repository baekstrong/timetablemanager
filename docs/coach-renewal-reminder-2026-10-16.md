# 코치 수업 전 재등록 안내 — 2026-10-16

## 동작

코치가 각 수업의 마지막 수업 대상과 수강 종료·미재등록자를 놓치는 문제를 줄인다. 해당 교시 실제 참석 예정자만 수업 시작 30분 전부터 시작 직전까지 한 팝업에 묶는다. 다음 등록이 이미 있으면 제외한다. 안내 구간 중 늦게 진입하거나 앱으로 복귀해도 표시한다.

- 후속 사용자 결정으로 **코치 오늘 페이지에만** 팝업을 표시한다. 시간표·게시판·훈련일지에서는 팝업용 명단 조회·시계·팝업을 실행하지 않는다. 오늘에서 벗어나면 열린 팝업과 리스너를 정리하고, 안내 구간 안에 오늘로 진입하면 미표시 대상만 안내한다.
- 같은 코치·날짜·교시 팝업은 브라우저 저장소에 표시 이력을 남겨 오늘 메뉴 재진입·새로고침으로 반복하지 않는다. 이름은 저장하지 않는다.
- 오늘 페이지의 등록/결제 등 다른 모달이 열려 있으면 닫힐 때까지 기다린다. 수업 시작 때는 안내 구간을 종료한다.
- 닫기·ESC·할 일 보기로 기존 미재등록 목록을 지우거나 등록·결제를 완료 처리하지 않는다.
- 앱이 닫혀 있어도 Netlify 예약함수가 같은 명단 기준으로 코치 기기에 묶음 푸시를 보낸다. 기존 알림 켜기와 유효 FCM 토큰이 필요하다.
- 훈련일지만 열려 있을 때도 푸시를 누르면 코치 오늘 페이지로 이동한다. 기존 게시판 푸시 처리는 유지한다.

## 대상 판정과 읽기

`_coachRenewalSource.js`는 Google Sheets의 최근 -6~+2개월 B:O와 과거 정지 등록 B:H, Firestore 보강·결석 신청·홀딩·휴일·비활성 교시를 읽는다. 이름/연락처 등 원본을 응답이나 로그로 반환하지 않고 안내 대상 이름만 코치 인증 API에 제공한다. 운영 데이터는 수정하지 않는다.

`_coachRenewalLib.js`는 기존 현재 등록 선택/일시정지/보강 종료일 규칙과 공용 `makeupEndDate`를 사용한다. 다음 등록·시작 전·종료 처리·휴일·휴강·홀딩·결석·합의결석·보강 이동을 제외하고 실제 보강 참석자를 반영한다. 같은 날 오전 보강과 저녁 정규가 함께 있으면 실제 마지막 교시에 마지막 수업을 안내한다.

인증 GET `/coach-renewal` 응답은 다음 구조다.

```json
{"date":"2026-10-16","lessons":[{"period":1,"startMinute":600,"lastNames":[],"delayedNames":[]}]}
```

모든 조회에 코치 ID 토큰을 확인하며 미인증 401·수강생 403·읽기 실패 503으로 응답한다. HTTP 캐시는 `private, no-store`, 서버 완료 캐시는 60초다. 등록 저장 뒤 `refresh=1`은 기존 진행 요청 완료 후 새 읽기를 공유해 이전 등록 응답을 최신 상태로 인정하지 않는다.

코치 오늘 페이지에 머무는 동안 브라우저는 15초 로컬 시계로 경계를 검사하며 매번 네트워크 조회하지 않는다. 진입·30분 전 경계·60초 이상 경과한 복귀·메인 등록 자료 변경 때 최신 명단을 읽는다. 실패한 자료나 계정 전환 전 요청으로 팝업을 열지 않는다.

## 예약 푸시와 배포

예약함수 `coach-renewal-reminder`의 UTC cron은 `*/10 0,2,8,10,12 * * 1-5`다. 평일 한국시간 09:30·11:30·17:30·19:20·21:10에 최초 대상 확인을 수행한다. 각 안내 구간 안의 후속 실행은 실패/지연을 보완하며, 구간 밖에는 운영 자료를 읽지 않는다.

수신자는 `users.isCoach === true`의 기기 토큰이며 파생 Firebase Auth 계정이 존재하고 활성 상태인지 확인한다. 날짜/교시/토큰 해시별 영수증을 `coachRenewalDeliveries`에 트랜잭션으로 선점한다. 발송 결과가 불명확한 경우 중복 가능성을 피하려 재발송하지 않는다. 무효 토큰은 원래 토큰과 같은 값일 때만 제거한다. 이름과 토큰 원문은 영수증·로그에 저장하지 않는다. `expiresAt` 필드만으로 TTL 삭제가 자동 활성화되지는 않는다.

일반 코드는 main push의 GitHub Pages 배포, 서버 두 함수는 Netlify 별도 배포다. `scripts/prepare-coach-renewal.mjs`가 자격증명 포함 번들을 Git 밖에 준비한다. 기존 정적파일과 기존 함수 digest를 유지하고 새 두 함수 및 예약 메타데이터만 추가한다. 프로젝트 키/번들/ZIP은 커밋하지 않는다.

## 오늘 페이지로 범위 정정

같은 날 사용자 후속 요청으로 팝업을 코치 오늘 페이지에만 한정했다. App에서 오늘 페이지일 때만 알림 컴포넌트를 연결하고, 훈련일지는 팝업 모듈·스타일·타이머·명단 조회·사전 로딩을 제거했다. 새 `coachRenewalPush.js`는 실제 푸시 클릭 시 코치 신원을 확인하고 오늘로 이동하는 기능만 제공하며 평상시 명단/토큰 조회를 하지 않는다. 서버 API·예약 푸시와 안내 대상 기준은 유지한다.

범위 정정 후 전체 101파일 900테스트·빌드·변경 ESLint 오류0 통과. 실제 App의 마운트 조건을 가져온 격리 브라우저에서 시간표/게시판 중 팝업과 안내 조회0, 오늘 진입 후 표시, 오늘 이탈 시 닫힘과 조회 종료, 같은 교시 오늘 재진입 중복 방지, 다음 교시 오늘 재진입, 학생/인증 해제, 320/390px을 확인했다. 로컬 검증 자료는 `outputs/coach-renewal-today-only-2026-10-16/`에 보관한다. 서버 재배포·운영 쓰기·실제 발송 테스트는 하지 않았다.
