# 보강 맞교환 (설계 단계, 2026-11-11)

## 배경
- 다음 주 신규가 입학반 뒤 일괄 시작하면 대부분 칸이 정원 7명으로 찬다. 보강 이동은 누가 홀딩·결석·보강으로 자리를 비워야만 가능하다.
- 기각된 안(사용자 판단):
  - 미리 결석 알림·결석 신고 보강권: 수강생은 결석을 수업 1~2시간 전에 정하고, 결석을 누른다는 건 이미 다른 날도 못 온다는 뜻이라 효과 없음.
  - 보강 전용 정원 +1: 신규가 일괄 시작해 실제로 8명이 들어온다.
  - 자율운동(3교시)을 보강으로 인정: 수강생 대부분 직장인이라 낮 시간 불가.

## 결정
- 정원을 늘리지 않고 두 사람이 서로 자리를 바꾸는 **맞교환**을 만든다.
- 짝 찾기는 두 가지:
  1. **자동 맞교환**: 서로 상대 칸을 원하는 보강 대기가 있으면 앱이 바로 확정한다.
  2. **맞교환 현황판**: 보강 대기가 현황판 글이 된다. 그 칸에 수업이 있고 규칙상 갈 수 있는 수강생이 `바꾸기`를 누르면, 올린 사람은 이미 동의한 것이므로 즉시 확정한다.
- 사용자 결정 (2026-11-11):
  - 확정 순간 두 사람에게 알림.
  - 받아주는 사람도 주간 보강 횟수 1회 사용.
  - 현황판은 **이번 주**만.
  - **이름 공개**.

## 설계 메모 (목업 기준, 구현 시 확정)
- 올리는 사람은 희망 칸을 여러 개 걸 수 있다. 역제안은 두지 않는다(직전 결정 패턴에 시간이 모자람). 같은 원래 수업의 희망 칸은 묶어서 보강 1회로 계산하는 안 — 현행은 대기 1건당 1회라 정책 확인 필요.
- 받는 사람에게도 기존 규칙 그대로: 정규 수업 요일로 이동 불가(`wouldDoubleBookDay`), 원래 시간표 칸 불가, 주간 보강 한도, 신청 마감.
- 확정 뒤 취소 불가(상대가 이미 내 자리에 있어 되돌리면 정원 초과).
- 확정은 두 보강을 한 번에 기록해야 한다(한쪽만 바뀌는 상태 금지). 확정 직전 두 사람의 원래 수업·보강 횟수를 다시 확인.
- 확정 알림은 푸시. 일정이 바뀌는 것이므로 올린 사람에게는 문자 폴백 검토.
- 신청 마감: 일반 보강과 같이 두 수업 모두 시작 2시간 전까지(2026-11-11 사용자 결정).
- 새 교환 요청 알림은 보내지 않는다. 알림은 확정 순간에만(2026-11-11 사용자 결정).
